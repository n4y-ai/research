### G-03: Trust propagation mechanics — formal model, max hop depth, decay function (High)

| Claim | Source(s) | Confidence | Notes |
|-------|-----------|------------|-------|
| TNA-SL (Jøsang): transitive trust via Subjective Logic opinions; series-parallel graph simplification; fusion operators; proven optimal (equals edge-splitting) | E3 | High | Well-established formal framework |
| Belief components multiply along chain; uncertainty accumulates: u^(n) ≈ u_avg^n → deep paths unreliable | E3 | High | Mathematical property of Subjective Logic |
| EigenTrust power iteration: t^(k) = α·C·t^(k-1) + (1-α)·p_pretrusted; converges if C stochastic and aperiodic | E1 | High | Perron-Frobenius theorem |
| TrustFlow: R_new[j] = α·Σ_i w(i→j)·f(R[i],e_ij) + (1−α)·T[j] + C[j]; unique fixed point via contraction mapping | E2 | Medium-High | Generalizes PageRank to vector reputation with topic-gated transfer |
| Optimal max hop depth: 3-4 hops for precision > 75%; hop 5 adds <5% new information (eBay data empirical) | MCP (citing Despotovic & Aberer 2006, Xiong & Liu 2004) | Medium-High | Empirical finding |
| Decay functions: exponential φ(h)=e^(-λh), power-law φ(h)=h^(-α), hyperbolic φ(h)=1/(1+βh); hyperbolic best empirical fit (R²=0.89 vs 0.81 exponential on eBay data) | MCP synthesis | Medium | Compiled from multiple sources |

**Status: SUBSTANTIALLY CLOSED** — Three formal models available (TNA-SL, EigenTrust, TrustFlow); hop depth and decay functions empirically characterized.

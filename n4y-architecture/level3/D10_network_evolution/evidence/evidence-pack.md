## Residual Notes

1. **Empirical validation gap**: Phase transition thresholds (E1 node counts, E41 Bass Diffusion) are based on analogues and models, not direct N4Y.AI measurements. Actual thresholds will require calibration during Birth phase.
2. **BELC 5-phase vs Moore 4-phase**: The N4Y.AI strategy uses 5 phases (Birth/Expansion/Authority/Leadership/Climax). Moore's original model uses 4 (Birth/Expansion/Authority/Renewal). The Leadership and Climax sub-phases within Authority/Renewal are N4Y-specific extensions that need design-time specification — covered by strategy audit claims but not externally validated.
3. **MNE quality control**: Machine-Generated Network Effects (E42) can amplify both value and harm. No proven governance framework yet for MNE quality at agent-economy scale.
4. **Collusion in agent markets**: RL agents can learn tacit collusion (Purdue 2026, from Cluster C Perplexity pass). This was not a gap in the original §6 but should be flagged as an emerging risk for L3/D10.

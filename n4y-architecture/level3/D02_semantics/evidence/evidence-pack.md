## Source Conflicts

| Conflict | Sources | Resolution |
|----------|---------|------------|
| Formal semantics vs pragmatic simplicity | E3 (FIPA modal logic) vs E1 (A2A flexible JSON, no formal preconditions) | Not contradictory — different design philosophies. N4Y.AI should use FIPA semantics for performative definitions but A2A transport/format for interop. |
| BDI mentalistic ACL semantics vs protocol-based semantics | E19, E21 (mentalistic) vs E22 (mixed intentional + institutional) | E22's hybrid approach resolves the tension. Recommend mixed model for N4Y.AI. |
| Security mandatory vs optional | E31 (A2A Security Framework: comprehensive defense) vs E33 (base A2A spec lacks mandatory security) | E31 is a third-party overlay, not part of core spec. N4Y.AI must mandate security at protocol level, not rely on optional add-ons. |
| Shared ontology vs no shared ontology | E3 (FIPA requires shared ontology) vs NLIP/Cursor Q1 (GenAI translates to local ontology, no shared required) | Context-dependent. N4Y.AI: use shared ES-ontology core + NLIP-style translation for cross-ecosystem edge cases. |
